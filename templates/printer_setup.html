Set up once, then print bills or tags from the workspace.

Shreyans CD410

Use the CD410 label driver for die-cut stickers. Load a continuous roll and switch to the receipt driver for bills and receipt tests.

Set up a label roll

  1. Measure one sticker face in millimetres. Enter the width across the roll and the height in the feed direction. Measure the gap separately.
  2. In CD410 Printing Preferences, create a custom paper size with those dimensions. Select Gap media for die-cut stickers and enter the measured gap if the driver asks for it.
  3. Run the manufacturer's label calibration after changing rolls. Make sure Feed advances one sticker at a time before printing.
  4. Use the tag preview to turn the artwork. Open Printer padding, alignment and saved profiles to correct edge clipping or a sideways shift. Save a profile for each roll you use on this device.
  5. Match the preview paper dimensions in the print dialog and keep extra driver rotation off. Set one page per sheet, 100% scale, no margins, no headers and no footers.
  6. Print one test label. Check all four edges, then print a single product tag and scan its QR before printing a batch.

PC or Mac · USB / Bluetooth

  1. Install the CD410 label driver for tags, or the receipt driver for continuous receipt paper, from the official setup page.
  2. Connect the printer and print a driver test page. For Bluetooth, follow the CD410 connection guide.
  3. For tags, set the driver paper width and height to the exact size shown in the tag preview. Calibrate the label gap with the manufacturer's tool.
  4. Choose CD410 in the print dialog, use 100% scale, and disable headers and footers. For tags, use no margins.

Android / iPhone / iPad

Install the manufacturer's app for your CD410 variant and connect inside that app. Print directly from the browser only if CD410 appears in the device's print dialog.

If it does not appear, use a compatible print service or the manufacturer's supported file-import workflow. Pairing alone does not enable browser printing. This website does not send raw Bluetooth commands.

Print is faint, skips labels or has the wrong size?

Confirm the thermal side faces correctly. Match the loaded paper dimensions in both the driver and preview, then calibrate the label gap. For faint QR codes, adjust darkness and speed in the driver and print one test label. Verify the ruler at 100% before printing a batch.

USB or Bluetooth

Test continuous receipt roll
  1. Install the official driver or mobile app for your model.
  2. Connect USB or pair Bluetooth as directed by the model's setup guide.
  3. Print a test page from the driver or app.
  4. Open a bill and choose Thermal receipt (58 or 80 mm), or open a product and choose Print tag.
  5. Use the matching paper size, 100% scale and turn off browser headers/footers.

The website opens your device's print dialog. Bluetooth printers must be supported by the device's print service or the manufacturer's app; pairing alone may not make a printer appear in the browser.
