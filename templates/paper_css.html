{# ============================================================================ PAPER TOKENS — for everything that ends up on paper. Deliberately separate from the app tokens in base.html, because paper has different needs: * pure black text, because thermal printers dither anything lighter and a mid-grey that looks fine on screen prints as mush; * no background tint to lean on — the sheet is the background; * ONE accent, so a shop's invoice, tag and statement look like they came from one shop rather than three. Include it once per document, before that document's own styles: {% include "paper_css.html" %} Documents that use it: view_invoice.html, statement.html, product_tag.html, tags_print.html, tags_calibrate.html. Adding a colour here is fine. Typing a hex into a print template is not — ui_audit.py fails the build on it. ============================================================================ #}
